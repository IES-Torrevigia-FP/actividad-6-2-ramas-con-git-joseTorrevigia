### Checkpoint 3 – Evidencia

#### Crea el archivo cp3-comparacion-ramas.md con:
- Una breve explicación de qué diferencias ves en app.txt entre main y feature-mensaje-bienvenida.
- Una frase que resuma con tus palabras qué hace git checkout al cambiar de rama.

Se puede observar que cuando cambias a la fama feature-mensaje-bienvenida aparece el texto nuevo con el mensaje de bienvenida y cuando regreso a la rama main ya no se ve dicho mensaje.

Al cambiar de rama con la orden git checkout se muestra la foto estatica de como esta esa rama en este momento. Al cambiar de una rama a la otra es como si tuviesemos dos copias de todo el trabajo pero independientes entre si aunque comparten parte de ese codigo.
